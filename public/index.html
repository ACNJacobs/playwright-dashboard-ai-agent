🤖 Welkom bij je AI Test Agent

                    

                        

                            
1

                            

                                Configureer je AI API
                                
Kies een AI provider (OpenAI, Azure, Claude, Grok, Ollama) en vul je API key in.

                            

                        

                        

                            
2

                            

                                Registreer een nieuwe site
                                
Klik op "➕ Nieuwe Site" en vul de naam en URL in.

                            

                        

                        

                            
3

                            

                                Laat de agent de site analyseren
                                
Klik op "🧠 Analyseren" om de agent de site te laten verkennen.

                            

                        

                        

                            
4

                            

                                Chat met de agent om tests te genereren!
                                
Vraag de agent om tests te maken, bijvoorbeeld: "Maak een test voor het login formulier"
